# MinecraftServer
Placer les scripts dans /Minecraft/Scripts\
Placer le server dans /Minecraft/Server\
Placer le fichier cron dans cron.d
Les backups seront dans /Minecraft/Backups\
Faire un chmod +x sur les fichiers de script\
\
Inspiration : https://github.com/kompetenzbolzen/minecraft-server-tools.git

cron logs : sudo tail -f /var/log/cron.log
